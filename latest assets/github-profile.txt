🔧 Featured Projects
🎬 VizTube — Video Platform with AI-Powered RAG
A decoupled FastAPI microservice streams video audio to Groq's Whisper API for transcription, generates embeddings locally with Hugging Face's all-MiniLM-L6-v2, and runs semantic search via pgvector + OpenRouter LLMs. The Node.js/Express core handles chunked uploads to Cloudinary and cascading relational data via Prisma. Fully containerized with Docker Compose, deployed to AWS EC2 through GitHub Actions CI/CD, with Nginx SSL termination and Cloudflare proxying.

    	
💬 EchoInbox — Anonymous Messaging & AI-Assisted Responses
A fully normalized PostgreSQL schema via Prisma, using NeonDB's serverless connection pooling to prevent exhaustion under Next.js Edge runtime load. Custom NextAuth credentials flow injects Zod-validated state and Resend OTP flags directly into JWT payloads, skipping redundant DB queries on route protection. Vercel AI SDK powers real-time streaming responses, with client-side debouncing to guard against API abuse.
