# Modern Web Stack Boilerplate & Setup Guide (2026)

**Modern Web Stack Boilerplate** is a battle-tested, standard-setting starter architecture and reference guide for modern web applications in 2026.

### Key Highlights & Technical Coverage

- **Next.js 16.2 Stack:** Configured for Next.js App Router with Turbopack defaults, React 19.2 Server Components, Server Actions, and Prisma 7 configuration (`prisma.config.ts`).
- **Express 5 API Architecture:** Native async error handling, modular routing patterns, CORS hardening, rate limiting, and environment variable schema validation with Zod.
- **Dual Database Paradigms:** Pre-configured database drivers and ORM setups for both relational (**PostgreSQL via Prisma ORM 7**) and document (**MongoDB via Mongoose 8 & Prisma ORM 7**).
- **Type Safety & Tooling:** Full TypeScript strict-mode enforcement, ESLint flat config, Prettier code formatting, and automated script workflows.

**Source Code:** [GitHub](https://github.com/Nishant-444/modern-web-boilerplate)
